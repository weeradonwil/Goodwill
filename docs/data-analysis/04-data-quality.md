# 04 — คุณภาพข้อมูลและประเด็นตรวจสอบ

## ผลตรวจไฟล์พื้นฐาน
- 464/464 worksheet CSV เปิดด้วย UTF-8 BOM aware parser (utf-8-sig) และ strict CSV mode ได้
- จำนวน record และความกว้างสูงสุดของแต่ละไฟล์ตรงกับ manifest
- ไม่มี worksheet CSV ขาดหรือเกิน; parse/decode errors เป็นศูนย์
- Hidden 458, Visible 6
- ยืนยันเฉพาะการอ่านโครงสร้าง CSV ไม่ได้ยืนยันความถูกต้องทางธุรกิจ

## Formula errors
พบ literal formula errors รวม 7,839 ค่า ใน 364 worksheet CSV:
- #N/A: 7,793
- #REF!: 46

บางแถวที่ INV ว่างยังมี #N/A ในช่องอื่น จึงต้องตรวจสูตร/แหล่งต้นทางและกำหนดว่าจะเก็บ raw error, null พร้อม error flag หรือแก้ source ก่อน import อย่าแทนด้วยค่าอื่นโดยเงียบ ๆ

## INV ว่าง, placeholder และซ้ำ
ใน transaction sheets พบ 12,828 แถวที่มี serial:
- 3,588 แถวมีช่อง INV ว่าง; 3,586 แถวยังมีข้อมูลอื่น และ 2 แถวมีเพียง serial
- 176 แถวใช้เครื่องหมายขีดแทน INV
- รหัสมีทั้ง numeric และ alphanumeric; เก็บเป็น string
- 9,064 occurrences มี 8,697 ค่าไม่ซ้ำ; 298 ค่า INV ซ้ำ รวม occurrences ส่วนเกิน 367
- 27 ค่า INV ซ้ำภายใน sheet เดียวกัน (30 occurrences ส่วนเกิน); 275 ค่า INV ซ้ำข้าม sheets (337 ส่วนเกิน)
- 4 ค่า INV ที่ซ้ำมีข้อความชื่อร้านค้าหลายแบบ

การซ้ำอาจเป็น split delivery, สำเนา/revision หรือ duplicate จริง ยังสรุปว่าเสียไม่ได้จนกว่าจะเทียบ source กับกฎธุรกิจ

## วันที่และชื่อชีต
- วันที่นำจ่ายใน transaction มีหลายรูปแบบ (เช่น D/M/YYYY, รูปแบบอื่น และ formula errors); พบวันที่ว่างอย่างน้อย 1 แถวในแถวข้อมูลที่ตรวจ
- อีก 207 ชีตไม่มีคอลัมน์วันที่จ่ายใน header
- BBF เป็นคนละแนวคิดกับวันที่จ่าย; พบรูปแบบเช่น YYYY/MM/DD
- ชื่อชีตมีรูปแบบ/ปฏิทินหลายชนิดและค่าผิดรูปหรือไม่ใช่วันที่ เช่น 31/07/259 และ ชีต467; อย่าอนุมานวันที่โดยไม่มี rule

## รายละเอียดสินค้าและแถวสรุป
- บล็อกสินค้าประกอบด้วย BBF, pallet, quantity แต่บางแถวไม่มีครบทุกช่อง
- พบแถวที่มีเฉพาะจำนวนหรือเฉพาะ BBF; อาจเป็นยอดรวม, สินค้าที่ไม่ใช้ pallet หรือข้อมูลไม่ครบ
- มีค่า quantity ที่ดูเป็น subtotal เช่น 223; ต้องแยก detail rows จาก subtotal/footer ก่อนคำนวณหรือ import
- ยังไม่ควรตั้ง NOT NULL ให้ทุกฟิลด์สินค้า/lot จนยืนยันกฎการกรอก

## QA และชนิดข้อมูล
- QA fields พบใน 103 sheets; checkbox มักเป็น TRUE/FALSE แต่บางช่องว่าง
- พบตัวเลขในบริบท QA อย่างน้อย 2 หัวข้อ เช่น 45 และ 60; อาจเป็น layout shift หรือข้อมูลผิด ต้องตรวจแถวต้นทาง
- pallet/จำนวนลังอยู่ในรูปข้อความ CSV; validate ตัวเลขและความหมายของ -, blank, formula error
- ชื่อสินค้า/ร้านค้ามีหลายรูปแบบ; ห้ามรวม alias จาก fuzzy match โดยไม่มีคนตรวจ
